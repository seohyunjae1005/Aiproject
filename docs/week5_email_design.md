# 5주차 1단계 — 이메일 리포트 미리보기

## 목적

구독자의 이메일 주소를 다루거나 실제 메일을 보내기 전에, 어떤 내용이 발송되는지 HTML 미리보기로 먼저 검토한다. 이 단계에서는 개인정보를 읽거나 저장하지 않으며 발송 기능도 실행하지 않는다.

## 처리 과정

1. 공개 웹사이트 데이터에서 최근 1일 기사만 선택한다.
2. 한국어 번역 제목과 요약이 있으면 우선 사용한다.
3. 월간 공정·양산기술 리포트의 제목과 핵심 변화를 상단에 배치한다.
4. 각 기사에 회사, 날짜, 기술 분야, 관련 직무와 공식 원문 링크를 넣는다.
5. 새 기사가 없으면 `발송 권장: 아니오`로 표시한다.
6. 생성한 HTML과 메타데이터를 GitHub Actions 결과물로만 제공한다.

## 개인정보 보호 원칙

- 현재 단계에서는 이메일 주소를 수집하지 않는다.
- 추적 픽셀이나 개인별 링크를 넣지 않는다.
- 실제 구독 단계에서는 Google Form으로 명시적 동의를 받고, 수신 동의 일시와 구독 해지 방법을 관리한다.
- 구독자 명단은 공개 GitHub 저장소에 커밋하지 않는다.

## 다음 승인 단계

미리보기의 내용과 형식을 검토한 뒤에만 Google Form·Sheet 연결과 메일 발송 코드를 추가한다. 실제 발송은 테스트 이메일 1개로 먼저 검증하고, 사용자의 명시적인 승인 없이 전체 구독자에게 발송하지 않는다.
