# 진로탐색수업 보고서 작성 기준

출처: `[진로탐색수업] 보고서 작성 가이드(학생).pdf` 6쪽 전체 확인

## 공통 제출 원칙

- 모든 보고서는 제출 후 지도교수 승인이 필요하다.
- 팀원 간 또는 주차 간 중복 내용은 제출로 인정되지 않는다.
- 한 보고서에 같은 날짜로 2시간 이상 등록할 수 있다.
- 하루 활동시간은 최대 8시간이며 이를 초과해 등록할 수 없다.
- 실제로 수행한 날짜와 시간만 입력한다.

## 주차보고서

### 필수 구성

1. 활동 목표
2. 수행내용 200자 이상
3. 성찰내용 200자 이상
4. 인증사진 1장 필수

### 수행내용 작성 기준

- 해당 주차의 주요 활동 과정 작성
- 실험·제작 절차나 관련 이론만 나열하면 인정되지 않음
- 본인의 역할, 행동, 판단과 문제 해결 과정이 드러나야 함

### 성찰내용 작성 기준

- 활동 결과만 요약하지 않음
- 활동을 통해 알게 된 본인의 흥미, 능력, 성격, 가치관 등을 작성
- 어떤 판단이 어려웠고 무엇을 새롭게 이해했는지 구체적으로 작성

### 첨부자료

- 촬영일시가 표시된 사진 1장 필수
- 활동시간 안에 촬영된 사진이어야 함
- 개인활동은 얼굴이 없어도 되지만 촬영일시는 보여야 함
- 화면 캡처도 가능하나 캡처 일시가 보여야 함
- 프로젝트 자료·활동 사진은 자료명을 붙여 한 파일로 묶어 첨부 권장
- 본문에 이미지를 직접 삽입하지 않음

## 중간보고서

- 각 주차의 주요 활동을 소제목 형태로 간략하게 정리
- 수행내용 500자 이상
- 목표달성도 200자 이상
- 향후계획 200자 이상
- 성찰내용 350자 이상
- 목표달성도는 수치와 부가 설명을 함께 작성하거나, 수치 없이 구체적으로 설명 가능
- 지도교수 승인 후 제출

## 결과보고서

- 중간보고서 최종 승인 후 작성 가능
- 각 주차 주요 활동을 소제목 형태로 정리
- 수행내용 500자 이상
- 목표달성도 200자 이상
- 성찰내용 350자 이상
- 향후계획 200자 이상
- 만족도조사와 사후조사 모두 제출해야 최종 제출 가능
- 만족도는 5점 척도이며 제출 후 응답 수정 불가
- 지도교수 승인 후 제출

## 프로젝트 적용 원칙

- 주차보고서는 계획이 아니라 실제 수행 결과를 기록한다.
- 목표 수치와 실제 결과를 구분한다.
- 실패한 수집 방식과 오류도 숨기지 않고 판단·개선 과정으로 기록한다.
- AI가 작성한 표현은 실제 활동과 본인의 생각에 맞게 수정한 후 제출한다.
- 타임스탬프 인증사진은 작업을 수행하는 당일에 직접 확보한다.
