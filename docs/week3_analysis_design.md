# 3주차 기사 본문 기반 직무 분석 설계

## 실행 안정성

- 기본 모델은 무료 구간에서 비교적 가벼운 `gemini-3.5-flash-lite`를 사용한다.
- 일시적인 429·5xx 오류는 지수형 대기와 임의 지연을 섞어 최대 3회 재시도한다.
- 계속 혼잡하면 `gemini-3.1-flash-lite`로 자동 전환한다.
- 초기 검증은 수동 실행으로 진행하고, 검증 후 일일 수집 작업에는 신규 분석을 최대 3건으로 제한해 연결한다.
- 회사별 최신 검증 결과와 기사 URL·분석 버전·원문 품질이 같으면 기존 결과를 재사용하고 Gemini를 다시 호출하지 않는다.
- 새 기사이거나 공식 요약보다 더 좋은 공식 본문을 확보한 경우에만 새 API 요청을 만든다.

확대 시험에서는 실행 화면에서 3건, 6건, 11건 중 하나를 직접 선택한다. 일일 자동 실행은 기존 PASS 결과를 재사용하고 새 분석만 최대 3건으로 제한한다.

## 대표 기사 선택 기준

- 11개 기업에서 최근 고관련 기사 최대 10건을 후보로 삼는다.
- 공정, 제조, 팹, 웨이퍼, 수율, 메모리, HBM, 패키징, EUV, 식각, 증착, 계측, 검사 관련 제목과 분류 신호에 가점을 준다.
- 배당, 실적, 인사, 수상과 행사 참여 중심의 발표는 후순위로 내린다.
- 기술성이 높은 순서대로 최대 5개 후보의 본문 추출을 시도하고, 회사별로 처음 성공한 한 건을 사용한다.

## 공식 본문 접근 실패 처리

- GitHub 서버를 차단하거나 응답이 느린 공식 사이트는 회사별 제한시간 안에서 다음 기술 기사 후보로 넘어간다.
- 모든 후보의 본문 접근이 실패해도 공식 RSS가 제공한 요약이 충분히 길 때만 제한적인 분석 입력으로 사용한다.
- 공식 RSS 요약을 쓴 결과에는 `official_feed_summary`를 기록하고 전체 신뢰도와 회사 영향 가설을 최대 `medium`으로 제한한다.
- 제목·분류처럼 짧은 정보밖에 없으면 억지로 분석하지 않고 해당 회사의 실패 사유를 로그에 남긴다.
- TSMC·Intel처럼 자동 실행 서버에서 공식 본문이 반복 차단되는 회사는 공식 목록의 제목·분류만 최소 입력으로 허용한다. 이때 사실은 제목에 명시된 1개로 제한하고, 직무는 최대 2개, 모든 확신도는 `low`로 표시한다.
- 이후 공식 본문을 확보하면 낮은 품질의 제목 기반 결과를 자동으로 교체한다.
- 외부 요약 사이트나 출처가 불분명한 우회 데이터는 사용하지 않는다.

## 검증 결과 보관

- 자동 검증을 통과한 결과만 회사별 캐시에 저장한다.
- 기사 본문과 AI 요청문은 캐시에 넣지 않고 자체 요약, 짧은 근거, 직무 인사이트만 보관한다.
- 같은 기사에 대해서는 실행할 때마다 임의로 교체하지 않는다. 새 기사이거나 공식 요약보다 더 좋은 본문 근거를 확보했을 때만 교체한다.
- 새 수집이나 분석이 실패하면 회사의 마지막 PASS 결과를 그대로 유지한다.
- 캐시 결과는 `machine_validated`로 기록하고 홈페이지에서는 반드시 `AI 참고용 초안` 경고와 원문 링크를 함께 표시한다.

## 목표

공식 기사 본문에서 확인되는 사실을 먼저 추출하고, 그 사실을 바탕으로 삼성전자·SK하이닉스의 반도체 기술 직무에서 고려할 가능성을 분석한다. 사실과 추론을 분리하고, 근거가 없는 공정 수치나 효과를 생성하지 않도록 출력 구조와 검증 기준을 고정한다.

## 분석 결과 구성

1. 한국어 핵심 요약
2. 원문에서 직접 확인되는 핵심 사실과 짧은 근거 구절
3. 핵심 기술 신호
4. 삼성전자·SK하이닉스에 미칠 수 있는 영향 가설
5. 관련 직무와 직무별 고려사항
6. 취업 준비생의 추가 학습 항목
7. 기사만으로 확인할 수 없는 내용
8. 분석 확신도

## 사실과 추론 구분 예시

- 사실: 회사가 기사에서 High NA EUV 도입 계획이나 적용 시점을 직접 발표함
- 추론: 도입 과정에서 공정 창 관리와 계측 중요성이 커질 가능성이 있음
- 확인 불가: 실제 수율 개선 폭, 장비 조건, 양산 원가와 내부 도입 일정

## 품질 원칙

- 사실에는 본문에 실제로 존재하는 25단어 이내의 짧은 영문 근거를 붙인다.
- 기사에 없는 수율, 비용, 공정 조건과 일정은 만들어내지 않는다.
- 직무는 기사와 관련성이 높은 1~4개만 선택한다.
- 기존 키워드 분류는 참고값으로만 사용하고 본문을 우선한다.
- AI 분석은 최종 판단이 아니라 공식 원문을 빠르게 검토하기 위한 1차 자료로 표시한다.

## 검증 후 자동 정리

- 25단어를 넘는 근거는 한국어 사실과의 대응 관계가 깨질 수 있으므로 해당 사실 전체를 제외한다.
- 원문에서 정확히 찾을 수 없는 근거와 그 사실 항목은 제외한다.
- 사실 항목이 5개를 넘으면 앞의 5개만 유지한다.
- 무엇을 축약하거나 제외했는지는 검증 보고서에 기록한다.
- 사실 근거가 모두 제외되면 15단어 이내의 원문 근거만 한 번 재생성하고 다시 검증한다.
- 정리 후에도 기준을 충족하지 못하면 게시하지 않고 `FAIL`로 남긴다.
- 본문 전체는 공개하지 않고 자체 작성한 요약과 짧은 근거만 게시한다.

## 1차 시험 대상

- Samsung Electronics 최신 핵심 기사 1건
- SK hynix 최신 핵심 기사 1건
- ASML 최신 핵심 기사 1건

먼저 3건을 사람이 원문과 비교하여 사실 정확성, 근거 일치, 직무 관련성, 과도한 추론 여부를 평가한 뒤 대상 기업과 기사 수를 확대한다.
