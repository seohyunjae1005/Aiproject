# Google Apps Script 시험 발송

이 코드는 Google Form 응답 Sheet 안에서만 실행한다. GitHub는 구독자 이메일에 접근하지 않는다.

## 안전 원칙

- `sendTestToLatestSubscriber`는 가장 최근의 유효한 신규 구독 신청 1건만 대상으로 한다.
- 최신 요청이 `구독 해지 요청`인 이메일은 대상에서 제외한다.
- 수신 동의 문구가 없는 행은 대상에서 제외한다.
- 새 기사가 없는 리포트는 발송하지 않는다.
- 현재 버전에는 전체 구독자 일괄 발송 함수와 예약 실행 기능이 없다.

## 연결 순서

1. 새 질문이 포함된 Google Form에서 본인 이메일로 `신규 구독 신청`을 다시 제출한다.
2. 응답 Sheet에서 `확장 프로그램 → Apps Script`를 연다.
3. 기본 코드를 지우고 `Code.gs`의 내용을 붙여 넣은 뒤 저장한다.
4. 함수 목록에서 `sendTestToLatestSubscriber`를 선택하고 실행한다.
5. 처음 한 번은 Google Sheets, 외부 URL 읽기와 이메일 발송 권한을 승인한다.
6. 본인 이메일 1건 수신 여부와 제목·링크·해지 안내를 확인한다.
