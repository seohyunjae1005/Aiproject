# 3주차 AI 직무 분석 시험 검토

## 시험 결과

- 대상: 삼성전자, SK하이닉스, ASML 공식 기사 각 1건
- API 호출 및 JSON 변환: 3/3건 성공
- 원문 근거 존재 여부 검사: 3/3건 통과
- 사람 검토 전 웹사이트 게시: 보류

## 확인한 장점

- 기사 요약, 기술 신호, 회사 영향 가설과 직무별 고려사항이 고정된 구조로 생성됐다.
- 기사에서 확인되는 사실과 회사에 미칠 수 있는 영향을 별도 항목으로 나눴다.
- 원문에 존재하지 않는 영문 근거는 자동으로 제외됐다.
- 기사만으로 알 수 없는 수율, 비용, 일정은 불확실성 항목에 표시됐다.

## 사람 검토에서 발견한 병목

1. 영문 근거가 실제 원문에 있더라도 한국어 사실 문장이 그 근거보다 넓은 내용을 포함할 수 있다.
2. 긴 영문 근거를 25단어로 자르면 뒤쪽 내용이 사라져 한국어 사실 전체를 뒷받침하지 못할 수 있다.
3. `stitching`을 `스태칭`, High-NA를 `고나치`로 표현하는 등 반도체 용어가 어색하게 번역될 수 있다.
4. 기계적인 PASS는 전문가 수준의 의미 검증 완료를 뜻하지 않는다.

## 개선 판단과 조치

- 긴 근거는 축약하지 않고 해당 사실 전체를 제외하도록 변경했다.
- 한국어 사실은 연결된 영문 근거 한 구절만으로 전부 확인되어야 한다는 규칙을 추가했다.
- High-NA EUV, stitching, availability, PDK의 권장 한국어 표기를 프롬프트에 고정했다.
- 공개 전에는 자동검사와 사람 검토를 모두 거치는 구조를 유지한다.

## AI 활용 경험으로 설명할 수 있는 부분

AI에게 요약만 요청한 것이 아니라 출력 형식을 설계하고, 실제 원문과 근거를 대조하는 검증 로직을 만들었다. 첫 시험에서 서버 혼잡과 근거 길이 문제를 발견해 대체 모델, 재시도, 부적합 사실 제거 기능을 추가했다. 이후 기계적 검사만으로는 의미 일치와 용어 품질을 완전히 보장할 수 없음을 확인하고 사람 검토 단계를 추가했다. 이 과정은 AI의 속도를 활용하면서도 결과를 그대로 신뢰하지 않고 검증 가능한 방식으로 사용하는 경험이다.
