# 반도체 핵심 기업 기술동향 AI 트래커

주요 메모리 제조사와 반도체 장비사의 공식 공개 정보를 매일 수집하고, AI가 사실과 공정 영향 가설을 분리해 구조화한 뒤 GitHub Pages와 opt-in 이메일로 제공하는 개인 프로젝트입니다.

## 현재 단계

- 1주차 진행 중
- 문제 정의 및 성공 기준 확정
- 공식 정보 채널 10개사 1차 조사
- 최소 완성 범위 6개사, 목표 범위 10개사로 설정
- 실제 수작업 기준시간 측정은 사용자 수행 후 기록 예정

## 핵심 원칙

- 공식 공개 정보만 사용합니다.
- 원문 사실과 AI의 추론을 구분합니다.
- 근거 링크가 없는 분석은 게시하지 않습니다.
- 구독은 명시적으로 동의한 사용자에게만 제공합니다.
- 실제 측정한 시간과 결과만 보고서에 기록합니다.

## 폴더

- `config/sources.yaml`: 수집 대상 회사와 공식 채널 초안
- `docs/week1_foundation.md`: 1주차 조사 및 설계 산출물
- `src/trend_tracker/`: 공통 수집 로직
- `scripts/fetch_samsung_rss.py`: 첫 번째 삼성전자 RSS 수집 프로그램

## 첫 실행

프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python scripts/fetch_samsung_rss.py
```

성공하면 `data/raw/samsung.json`에 최신 기사 목록이 저장됩니다. 이 파일은 반복 실행 데이터이므로 Git에는 올리지 않습니다.
